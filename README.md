# Environment Setup

## a) (Mini)Conda environment:

- Creation:
```bash
conda create -n env_name python= -y
```
- Activation:
```bash
conda activate env_name
```

- Installation of dependencies:
```bash
conda install --file requirements.txt -y
```

## b) Without conda:

- Create a virtual environment:
```bash
python -m venv env_name 
```
- Activation:
```bash
source env_name/bin/activate # if you are using Linux or macOS
# or
env_name\Scripts\activate # if you are using Windows
```

- Installation of dependencies:
```bash
pip install -r requirements.txt
```

### C) Using uv

- Create a virtual environment (you can specify the Python version):
```bash
uv venv env_name --python 
```

- Activation:
```bash
source env_name/bin/activate # Linux or macOS
# or
env_name\Scripts\activate # Windows
```

- Installation of dependencies:
```bash
uv pip install -r requirements.txt
```
