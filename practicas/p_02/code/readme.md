## Ejecución reproducible

El flujo final se ejecuta desde cualquier directorio con:

```bash
python practicas/p_02/code/main_final.py
```

El ejecutor corre, en orden, `main.ipynb`, `main_b.ipynb` y `main_c.ipynb`.
Las copias ejecutadas se guardan en `code/executed/`; las figuras se generan
en `report/plots/` y los resultados en `results/`.

El documento final es `report/reporte_completo.tex`. El archivo `repot.tex`
se conserva únicamente como borrador histórico y no debe compilarse ni
entregarse.
